# 📗 JavaScript — Orientação a Objetos (Udemy)

Anotações e exercícios do módulo de **objetos, protótipos e orientação a objetos** em JavaScript.

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## 📚 Conteúdo

- **Objetos:** métodos úteis, `defineProperty`, getters e setters, `Map`
- **Funções construtoras:** factory functions e constructor functions
- **Protótipos:** prototype chain, manipulação de protótipos, herança e polimorfismo
- **Classes ES6:** criação de classes, herança, métodos estáticos, getters e setters
- **Projeto:** validação de formulário com validação de CPF (`Orientação a Objeto/Validando um formulario`)

## 🚀 Como testar

Os arquivos `.js` podem ser executados com Node:

```bash
node "Aulas/Prototypes.js"
```

O projeto de formulário roda abrindo o `index.html` no navegador.
